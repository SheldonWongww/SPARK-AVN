# Open-source references

`repos/` is a local, Git-ignored clone cache. Reference repositories must remain unmodified; active research changes belong under `avn/`, `vln/`, `objectnav/`, or `core/`.

`catalog.json` pins the upstream URL and commit for reconstruction. Existing dirty working trees from the pre-refactor workspace are preserved here as historical references and are not considered part of the clean top-level Git state.
